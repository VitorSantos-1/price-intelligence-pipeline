Multi-IA Operacional • OCR Vision por Screenshot • 11 Supermercados • Compilador em Executável (.exe)

🚀 Evolução do projeto (app desktop “Falcons Data”)

O pipeline de scraping é unificado a um cluster de Inteligência Artificial Conjunta (GPT-4o, Gemini 1.5 Flash e Groq) e à leitura visual por OCR de tela para produtos difíceis de rastrear. As versões mais recentes acrescentaram navegação completa por categoria, um monitor de preços e o cadastro de sites customizados pelo usuário.

⚠️ Nomes de rede abaixo são fictícios, apenas para demonstração.

🛒 Aurora Supermercados 🛒 Mercadinhos Vizinho 🛒 Atacado Uno 🛒 Atacado Dois 🛒 Rede Continental 🛒 Estrela Supermercados 🛒 Economize Supermercados 🛒 Rede Horizonte 🛒 Mega Economia 🛒 Atacarejo Litoral 🛒 Cedro Supermercados

🤖 Multi-IA Conjunta

  • GPT-4o Mini: Normaliza nomes digitados e sugere termos alternativos de busca.
  • Vision OCR: Captura screenshot da página e usa GPT-4o / Gemini Flash para ler nome, preço e EAN direto da imagem.
  • Resumos Inteligentes: Analisa menor preço, diferença percentual e ofertas automaticamente.

🔍 Estratégia de Busca Híbrida

  • API VTEX / JSON: Chamadas nativas de alta velocidade para as redes que expõem catálogo VTEX.
  • Barra do Google: Digita "produto + supermercado" direto no Google para contornar bloqueios.
  • Fallback Visual: Se tudo falhar, tira screenshot da tela e extrai visualmente.

📦 Geração de Executável (.exe)

  • Sem dependências de Python no computador do cliente final.
  • Inclui script gerar_executavel.py (PyInstaller automático).
  • Arquivo de projeto installer_config.iss para Inno Setup.

🛠️ Como Executar ou Compilar

Para rodar em modo desenvolvimento:

python v4/pesquisa_preco_v4.py

Para gerar a pasta executável (.exe):

python v4/gerar_executavel.py
